# Presets System

Oh-my-opencode includes a presets system for quickly switching between model configurations.

## Available Presets

| Preset | Cost | Best For |
|--------|------|----------|
| balanced | Moderate | Daily development |
| best | High | Critical projects |
| free | \/usr/bin/bash | Learning |
| maintainer-default | High | Official recommendations |

## Usage

Linux/WSL: ~/.config/opencode/presets/switch-preset.sh balanced
Windows: ~/.config/opencode/presets/switch-preset.ps1 balanced

## Installing

cp -r presets ~/.config/opencode/

See presets/README.md for full documentation.
